# Benchmarks with the on-device name model

> Generated by `pnpm --filter @maskit/bench bench:ner`. Needs the model files (`pnpm --filter @maskit/ner fetch-model`). Do not edit by hand.

The optional model finds names, organizations and places in free text, where the rules need a label such as "Patient:" or "Dr.". Model: `onnx-community/distilbert-NER-ONNX` (DistilBERT fine-tuned for English named-entity recognition, 8-bit quantized, about 66 MB), run locally; hits pass through the same level, confidence and overlap rules as the rules do, after generic filters (greeting words, sentence-opening verbs, short all-caps abbreviations, lowercase words, dotted initials).

**Same caveats as BENCHMARKS.md:** the same 32 hand-written documents, labeled by the author, English only. The filters were chosen after looking at this model's mistakes on this set, so the numbers are somewhat optimistic for unseen text.

## What is still missed or wrongly flagged

- Default (standard) level, false alarms: none
- Strict level, missed: `ORGANIZATION: Northwind Traders`, `MEDICAL_RECORD_NUMBER: A2291847`, `DATE_OF_BIRTH: 3 de marzo de 1971`, `ORGANIZATION: Initech`
- Strict level, false alarms: `LOCATION: Paciente`

## Limits
- English only. The model was trained on news text, so unusual or non-Western names, lowercase text and short chat messages are weaker.
- Organizations and places depend on the model; a company named like a common word may be missed.
- Adds a 66 MB download and about 20 ms per sentence on a laptop CPU.
